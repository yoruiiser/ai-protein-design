
# AI-Driven De Novo Protein Design

An independent computational biology project exploring
generative AI for designing novel protein structures.

## Objectives

- Understand generative protein design.
- Explore RFdiffusion for backbone generation.
- Investigate ProteinMPNN for sequence design.
- Study structure prediction using AlphaFold.
- Analyze generated protein structures computationally.

## Technologies

- Python
- PyTorch
- Biopython
- NumPy
- Matplotlib
- RFdiffusion
- ProteinMPNN
- AlphaFold
- Google Colab

## Project Structure

- `notebooks/`: Computational experiments
- `src/`: Python source code
- `data/`: Input biological data
- `results/`: Experimental outputs
- `docs/`: Documentation
- `figures/`: Scientific visualizations

## Current Status

Project initialization and literature review.

## Note
Computational predictions do not establish
experimental protein stability or biological function.
